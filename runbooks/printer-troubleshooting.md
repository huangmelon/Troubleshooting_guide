# 印表機無法連線排障手冊   


**分類:** 印表機問題  
**適用系統：** Windows 10 / 11  
**預估處理時間：** 15–30 分鐘  
**最後更新：** 2026-03

---

## 問題描述

使用者反映以下其中一種狀況：
- 印表機顯示「離線」
- 按下列印後沒有反應
- 找不到印表機裝置
- 列印佇列卡住無法清除
- 無線印表機無法連線

---  

## 第一步：判斷印表機類型

先確認連線方式，因為排查方向不同：

| 連線方式 | 常見問題 |
|---|---|
| USB 直接連接 | 線材、驅動程式、USB 埠問題 |
| 區域網路（有線/無線） | IP 位址、網路連線問題 |
| 共用印表機（透過其他電腦） | 共用設定、權限問題 |  

---

## ⚠️ 特殊狀況：列印佇列卡住

若列印佇列有卡住的工作無法刪除，先執行以下步驟再繼續排障：

1. 按 `Win + R` 輸入 `services.msc` → Enter
2. 找到 **Print Spooler** → 右鍵 → **停止**
3. 開啟檔案總管，前往以下路徑並刪除所有檔案（資料夾本身不要刪）：
```

C:\Windows\System32\spool\PRINTERS
```
4. 回到 services.msc → Print Spooler → 右鍵 → **啟動**
5. 重新嘗試列印

---  
## Step 1：確認基本硬體狀態

- [ ] 印表機電源是否開啟
- [ ] 印表機面板是否有錯誤訊息或警示燈
- [ ] 紙張是否放好，是否卡紙
- [ ] 墨水或碳粉是否足夠
- [ ] USB 線是否確實插緊（USB 連線適用）

---  
## Step 2：重新啟動所有裝置

1. 關閉印表機電源，等待 30 秒後重新開啟
2. 重新啟動電腦
3. 若為無線印表機，同時重啟路由器
4. 等待所有裝置完全啟動後再測試

---  
## Step 3：確認印表機狀態為「線上」

1. 設定 → 藍牙與裝置 → 印表機與掃描器
2. 點選目標印表機
3. 若顯示「離線」：
   - 點**開啟列印佇列**
   - 上方選單 → **印表機** → 確認「使用離線印表機」**未勾選**

---  
## Step 4：確認為預設印表機

1. 設定 → 藍牙與裝置 → 印表機與掃描器
2. 關閉「讓 Windows 管理預設印表機」
3. 右鍵目標印表機 → **設定為預設印表機**

---  
## Step 5：檢查 USB 連線（USB 適用）

1. 拔除 USB 線，換一個不同的 USB 埠重新插入
2. 嘗試更換 USB 線
3. 裝置管理員確認印表機是否有出現，是否有黃色警示符號

若有黃色警示符號 → 跳到 Step 7（重新安裝驅動程式）

---  
## Step 6：確認網路連線（無線/網路印表機適用）

### 確認印表機 IP 位址

從印表機面板列印「網路設定頁」或「狀態報告」，取得印表機目前的 IP 位址。

### 測試網路連通性

開啟命令提示字元，輸入（將 x.x.x.x 換成印表機實際 IP）：
```cmd
ping x.x.x.x
```

**判斷結果：**  

| 結果 | 代表意思 | 處理方式 |
|---|---|---|
| 有回應（Reply from...） | 網路連線正常 | 繼續 Step 7 |
| Request timed out | 電腦無法連到印表機 | 檢查是否同一網段 |
| 無法連線 | 印表機未連上網路 | 重新設定印表機 Wi-Fi |

### 確認 IP 位址固定

若印表機 IP 會變動，建議在路由器設定中將印表機 IP 綁定（DHCP Reservation），避免 IP 改變後電腦找不到印表機。

---  
## Step 7：重新安裝驅動程式

1. 設定 → 藍牙與裝置 → 印表機與掃描器
2. 點選目標印表機 → **移除**
3. 前往印表機製造商官網下載最新驅動程式：
   - HP：support.hp.com
   - Canon：canon.com.tw
   - Epson：epson.com.tw
   - Brother：brother.com.tw
4. 執行安裝程式，依照指示完成安裝
5. 重新啟動電腦後測試

---  

## Step 8：執行 Windows 印表機疑難排解

1. 設定 → 系統 → 疑難排解 → 其他疑難排解員
2. 找到**印表機** → 點**執行**
3. 依照指示完成排解
4. 重新測試列印

---  

## Step 9：檢查 Print Spooler 服務

1. 按 `Win + R` 輸入 `services.msc` → Enter
2. 找到 **Print Spooler**
3. 確認狀態為**執行中**，啟動類型為**自動**
4. 若未執行 → 右鍵 → **啟動**
5. 若已執行但有問題 → 右鍵 → **重新啟動**

---  

## Step 10：檢查共用印表機設定（共用印表機適用）

若印表機是透過另一台電腦共用：

1. 確認主機電腦已開機且登入
2. 確認主機電腦上的 Print Spooler 服務正在執行
3. 主機電腦：控制台 → 裝置和印表機 → 右鍵印表機 → **印表機內容** → **共用** 分頁，確認共用已開啟
4. 確認兩台電腦在同一個網路
5. 嘗試重新新增網路印表機：設定 → 藍牙與裝置 → 新增裝置

---  

## 常見錯誤訊息對照表

| 錯誤訊息 | 可能原因 | 解決方式 |
|---|---|---|
| 印表機離線 | 連線中斷或設定問題 | Step 3 |
| Driver unavailable | 驅動程式遺失或損毀 | Step 7 |
| Print spooler 服務未執行 | 服務異常停止 | Step 9 |
| 存取被拒 | 權限問題 | Step 10 |
| 列印佇列卡住 | Spooler 暫存檔損毀 | 特殊狀況 |
| 找不到印表機 | 網路或驅動問題 | Step 6 → Step 7 |
