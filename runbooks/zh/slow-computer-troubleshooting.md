# 電腦執行速度緩慢排障手冊  

**分類：** 系統效能問題  
**適用系統：** Windows 10 / 11  
**預估處理時間：** 20–40 分鐘  
**最後更新：** 2026-03  

---

## 問題描述

使用者反映以下其中一種狀況：
- 電腦開機很慢
- 程式開啟需要很長時間
- 操作時頻繁出現當機或無回應
- 風扇聲音很大但電腦還是很慢
- 電腦用一段時間後越來越慢

---

## 第一步：先收集基本資訊

處理前先問使用者以下問題，縮小排查範圍：

| 問題 | 可能方向 |
|---|---|
| 是一直都慢還是最近才變慢？ | 最近才慢 → 可能是更新、新軟體、病毒 |
| 開機就慢還是用一段時間才慢？ | 開機就慢 → 開機程式太多；用久才慢 → 記憶體洩漏或散熱 |
| 所有程式都慢還是特定程式慢？ | 特定程式慢 → 該程式本身問題 |
| 最近有安裝什麼新軟體嗎？ | 有 → 可能是新軟體造成衝突 |
| 電腦使用幾年了？ | 超過 5 年 → 可能是硬體老化 |

---

## Step 1：檢查目前資源使用狀況

開啟工作管理員快速診斷：

1. 按 `Ctrl + Shift + Esc`
2. 點**效能**分頁
3. 觀察以下數值：

| 項目 | 正常範圍 | 需要注意 |
|---|---|---|
| CPU | 閒置時低於 20% | 持續高於 80% |
| 記憶體 | 低於 80% | 高於 90% |
| 磁碟 | 低於 50% | 持續 100% |
| GPU | 依使用情境 | 閒置時持續高於 50% |

4. 點**處理程序**分頁，依 CPU 或記憶體排序，找出佔用最多資源的程式

---

## Step 2：結束佔用資源的程式

1. 工作管理員 → **處理程序**分頁
2. 找到佔用大量 CPU 或記憶體的程式
3. 右鍵 → **結束工作**

**注意：** 以下程式即使佔用資源也不要結束：
- System / System Idle Process
- Windows Security
- antimalware service executable（Windows Defender）

---

## Step 3：清理開機自動啟動程式

開機程式太多是最常見的原因之一：

1. 工作管理員 → **啟動**分頁
2. 查看每個程式的「啟動影響」
3. 右鍵不需要開機自動啟動的程式 → **停用**

建議停用的常見程式：
- Spotify、Discord、Teams（需要時再手動開啟即可）
- OneDrive（若不常用）
- 各種軟體的更新程式

**不要停用：**
- Windows Security
- 音效、顯示卡驅動相關程式
- 任何你不確定用途的系統程式

---

## Step 4：檢查磁碟空間

磁碟空間不足會嚴重影響效能：

1. 開啟檔案總管 → 本機
2. 確認 C 槽剩餘空間

| 剩餘空間 | 狀態 |
|---|---|
| 20% 以上 | 正常 |
| 10–20% | 建議清理 |
| 低於 10% | 需要立即清理 |

### 執行磁碟清理

1. 搜尋「磁碟清理」→ 選擇 C 槽
2. 勾選所有項目
3. 點**清理系統檔案**，再次勾選所有項目 → 確定

---

## Step 5：檢查是否有惡意程式

病毒或惡意程式是造成電腦變慢的常見原因：

1. 開始 → **Windows 安全性**
2. **病毒與威脅防護** → **快速掃描**
3. 若發現威脅，依照指示處理
4. 若懷疑有惡意程式但掃描沒結果，執行**完整掃描**（需要較長時間）

---

## Step 6：執行磁碟重組或最佳化

1. 搜尋「重組並最佳化磁碟機」
2. 選擇 C 槽 → 點**最佳化**

**注意：**
- HDD（傳統硬碟）→ 執行「重組」
- SSD（固態硬碟）→ 執行「最佳化（Trim）」，不要執行重組

不確定是 HDD 還是 SSD：
```cmd
winsat disk
```
結果包含「Timed Sequential Write」速度若超過 400MB/s 通常為 SSD。

---

## Step 7：更新 Windows 與驅動程式

過時的系統和驅動程式可能造成效能問題：

1. 設定 → Windows Update → **檢查更新**
2. 安裝所有可用更新
3. 裝置管理員 → 逐一檢查顯示卡、網路卡、晶片組驅動程式是否為最新版本

---

## Step 8：調整電源設定

確認電源計劃設定為高效能：

1. 控制台 → 電源選項
2. 選擇**高效能**（筆電需插電才建議使用）

若找不到高效能選項：
```cmd
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
```
執行後重新開啟電源選項即可看到。

---  

## Step 9：檢查散熱狀況

CPU 過熱會自動降頻保護，造成效能下降：

使用免費工具 **HWMonitor** 或 **Core Temp** 檢查溫度：

| 元件 | 正常溫度 | 需要注意 |
|---|---|---|
| CPU 閒置 | 30–50°C | 高於 70°C |
| CPU 負載中 | 60–80°C | 持續高於 90°C |
| SSD | 30–50°C | 高於 70°C |

若溫度過高：
- 確認筆電散熱孔未被遮住
- 清潔風扇散熱孔（可用罐裝空氣噴罐）
- 考慮重新塗抹散熱膏（需要有經驗者處理）

---

## Step 10：評估硬體升級

若以上步驟都試過，效能仍然不佳，可能是硬體規格不足：

| 升級項目 | 效果 | 難度 | 費用參考 |
|---|---|---|---|
| 加裝 RAM | 改善多工效能 | 低 | 約 NT$500–2,000 |
| 換 SSD | 大幅提升開機與讀寫速度 | 中 | 約 NT$1,500–4,000 |
| 重新安裝 Windows | 清除累積問題 | 中 | 免費 |

**最有效的升級順序：**
1. 若 C 槽是 HDD → 換 SSD（效果最顯著）
2. 若 RAM 低於 8GB → 加裝至 16GB
3. 以上都做了還是慢 → 考慮重新安裝 Windows

---

## 常見狀況對照表

| 症狀 | 最可能原因 | 優先檢查 |
|---|---|---|
| 開機很慢 | 開機程式太多 | Step 3 |
| 用久才變慢 | 記憶體洩漏或散熱 | Step 1、Step 9 |
| 磁碟持續 100% | 病毒或系統問題 | Step 5、Step 6 |
| CPU 持續高使用率 | 惡意程式或程式衝突 | Step 2、Step 5 |
| 風扇一直狂轉 | CPU 過熱 | Step 9 |
| 最近才突然變慢 | 更新或新軟體問題 | Step 7、Step 3 |
