# Wi-Fi 無法連線排障手冊

**分類:** 網路問題  
**適用系統:** Windows 10 / 11  
**預估處理時間:** 10-20 分鐘  
**最後更新:** 2026-03  

---

## 問題描述

使用者反映以下其中一種狀況:  
1.找不到 Wi-Fi 網路  
2.可以看到網路但無法連線  
3.連線後顯示「已連線，無網際網路存取」  
4.工作列上的Wi-Fi 圖示完全消失  
5. **Wi-Fi 圖示間歇性消失 (有時出現、有時不見)**  

---  

## 第一步: 判斷影響範圍

先問使用者這個問題: **其他裝置(手機、平板)也無法連線嗎?**
- **是 -> 多台裝置都有問題: 問題在路由器或ISP，跳到 Step 2B**
- **否 -> 只有這台電腦有問題: 問題在電腦本身，從 Step 1 開始**

---  

## ⚠️特殊狀況:Wi-Fi 圖示完全消失  

若工作列上完全看不到 Wi-Fi 圖示，先執行以下檢查，再繼續一般排障步驟。  

### 檢查A1: 確認圖示是否被隱藏  

1.右鍵點選工作列空白處 -> **工作列設定**
2.找到**系統匣圖示** (或「通知區域」) 
3.確認**網路**圖示是否已開啟  

### 檢查A2: 重新啟動 Windows 檔案總管

1. 按`Ctrl + Shift + Esc` 開啟工作管理員  
2. 找到 **Windows 檔案總管(explorer.exe)**  
3. 右鍵**重新啟動**  
4. 等待幾秒，圖示應該會出現

### 檢查A3: 確認網路卡是否被停用  

1.右鍵點選**開始** -> **裝置管理員**  
2.展開**網路介面卡**  
3.若 Wi-Fi 介面卡有灰色向下箭頭 -> 右鍵 -> **啟用裝置**  

### 檢查A4: 確認 WLAN AutoConfig 服務是否運作中  

1. 按 `Win + R` 輸入 `services.msc` -> Enter
2. 找到 **WLAN AutoCongfig**
3. 確認狀態為**執行中**，啟動類型為**自動**
4. 若未執行 -> 右鍵 -> **啟動**  

若以上四個檢查都正常但圖示仍消失 -> 繼續 Step 6 (更新驅動程式)   

---

## ⚠️ 特殊狀況B: Wi-Fi 圖示間歇性消失  

若Wi-Fi 圖示有時出現、有時消失，先用下表判斷可能原因:  

| 狀況 | 最可能的原因 |
|---|---|
| 電腦閒置一段時間後消失 | 電源管理設定 |
| 隨機消失，沒有特定時間點 | 驅動程式不穩定 |  
| 移動筆電或開合螢幕時消失 | 硬體接觸不良 | 
| 某次 Windows 更新後才開始 | 驅動相容性問題 |  

### 檢查B1: 關閉電源管理 (最常見原因，先從這裡開始)  

1. 裝置管理員 -> 網路介面卡 -> 右鍵 Wi-Fi 介面卡 -> **內容**
2. 點 **電源管理** 分頁
3. 取消勾選 「允許電腦關閉這個裝置以節省電源」
4. 點確定，觀察是否還會消失

### 檢查B2: 更新或退回驅動程式  

若問題是從某次更新後才開始: 
1. 裝置管理員 -> 網路介面卡 -> 右鍵 Wi-Fi 介面卡 -> **內容**
2. 點 **驅動程式** 分頁-> **回復驅動程式**

若問題一直存在但驅動版本較舊:  
1. 記下介面卡名稱
2. 前往製造商官網下載最新驅動程式並安裝

### 檢查B3:硬體問題 (筆電適用)  

若問題在移動筆電或開合螢幕時發生，且軟體層面無法解決:  
-紀錄問題發生的條件與頻率  
-建議送交維修人員檢查wifi模組接觸狀況  
-暫時替代方案: 使用 USB Wi-Fi 介面卡  

### 檢查B4: 確認 Windows 更新狀態  

1.設定 -> Windows Update -> 檢查更新  
2. 若有待安裝的更新，先完成更新再觀察
3. 若更新後問題消失，代表是驅動相容性問題已修復

## Step 1: 確認基本狀態

-[ ] 確認未開啟飛航模式 (右下角工作列)  
-[ ] 確認 Wi-Fi 開關已開啟  
-[ ] 確認可以看到 SSID (網路名稱) 出現在清單中  

若完全看不到任何 Wi-Fi 網路 -> 可能是網路卡驅動問題，跳到 Step 5

---

## Step 2A: 重新啟動裝置 (單一裝置問題)

1.重新啟動電腦  
2.重新嘗試連線  

若仍無法連線 -> 繼續 Step 3  

---

## Step 2B: 重新啟動路由器 (多台裝置問題)

1. 將路由器電源線拔除  
2. 等待30秒  
3. 重新插上電源，等待2分鐘讓路由器完全啟動  
4. 重新嘗試連線  

若仍無法連線->聯絡ISP(網路供應商)  

---

## Step 3: 重新連線網路

1. 點右下角 Wi-Fi 圖示  
2. 找到目標網路 -> 點「忘記」  
3. 重新選擇網路並輸入密碼  

---

## Step 4: 檢查 IP 位址

開啟命令提示字元 (以系統管理員身分執行):  
```cmd
ipconfig /all
```

**判斷結果:** 

| IP位址顯示 | 代表意思 | 處理方式 | 
|---|---|---|
|192.168.x.x| 正常取得IP | 繼續下一步 |
|169.254.x.x| DHCP 失敗 | 執行以下指令 |
|空白| 網路卡未啟用 | 跳到 Step 5 |

若 IP 為169.254.x.x，執行:
```cmd
ipconfig /release
ipconfig /renew 
```

---


## Step 5: 重設網路設定

以系統管理員身分開啟命令提示字元，依序執行: 
```cmd
netsh winsock reset
netsh int ip reset
ipconfig /flushdns 
```

執行完畢後**重新啟動電腦**，再測試連線。


---

## Step 6: 更新網路驅動程式

1. 右鍵點選「開始」-> 裝置管理員
2. 展開網路介面卡
3. 右鍵點選 Wi-Fi介面卡 -> 更新驅動程式
4. 選擇自動搜尋驅動程式

若自動更新無效，記下介面卡名稱，前往製造商官網下載最新驅動程式

---

## 常見錯誤訊息對照表

| 錯誤訊息 | 可能原因 | 解決方式 | 
|---|---|---|
|無法連線至此網路 | 網路設定損毀 | Step 3 (忘記並重連)|
|DNS 伺服器未回應| DNS 設定問題| 手動改為 8.8.8.8 |
| 已連線，無網際網路存取 | IP 衝突或閘道問題 | Step 4 |
| 找不到任何網路 | 驅動程式問題 | Step 6 | 
|Wi-Fi 圖示消失 | 圖示隱藏/網路卡停用/驅動問題| 特殊狀況 A |  
|Wi-Fi 圖示間歇性消失 | 電源管理/驅動不穩/硬體問題 | 特殊狀況 B |


---

## DNS 手動設定方法 (補充) 

1. 控制台 -> 網路和共用中心 -> 變更介面卡設定
2. 右鍵 Wi-Fi -> 內容
3. 選取 **網際網路通訊協定第4版 (TCP/IPv4)** -> **內容**
4. 選擇**使用下列DNS 伺服器位址**:
   - 慣用: `8.8.8.8` (Google)
   - 其他: `1.1.1.1` (Cloudflare)
