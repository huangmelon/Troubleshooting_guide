## 關於這個作品集  

本作品及紀錄了常見的 IT Support 問題的排障流程與解決方式，  
內容涵蓋網路、印表機、系統效能等日常 Help Desk 情境。  

所有文件依照實際工作場景設計，目標是讓任何人都能跟著步驟解決問題。
